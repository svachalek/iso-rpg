The Rig_Medium clips from KayKit - Character Animations 1.1 by Kay
Lousberg (https://kaylousberg.itch.io/kaykit-character-animations), CC0,
see LICENSE.txt. Each file is the pack's mannequin carrying one theme's
animations; the mannequin's skeleton has the same bones and rests as the
Adventurers characters', so scripts/figure.gd reads the files named in
Figure.PACK_FILES once, renames the track paths to the characters' rig and
adds the clips to every model's player. The .gdignore keeps the editor
from importing the files as scenes.
