The skeletons and their weapons from KayKit - Character Pack : Skeletons 1.1
by Kay Lousberg (https://kaylousberg.itch.io/kaykit-skeletons), CC0, see
LICENSE.txt. Only the models in use are here, copied from the full pack
(assets/KayKit_Skeletons_1.1_EXTRA, ignored by git and Godot): the
characters from characters/gltf and the weapons, with the shared texture,
from assets/gltf. The characters carry no animations; they are on the same
Rig_Medium skeleton as the Character Animations pack, whose clips
scripts/figure.gd adds to them. The weapons are separate models that
scripts/monsters.gd hangs off the hand bones. Loaded at runtime; the
.gdignore keeps the editor from importing them.
